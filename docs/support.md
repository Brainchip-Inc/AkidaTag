# AkidaTag support

## Before you ask

- [Troubleshooting](user-guide.md#9-troubleshooting) in the user guide covers the failures people
  hit most: the tag not found, an update refused, a model not running.
- The [FAQ](faq.md) answers the common questions.
- The [release notes](release-notes.md) list the known issues of each firmware release.

## Where to ask

1. **BrainChip's Discord**, at https://discord.com/invite/9bmd9g52vn, for help, questions and
   discussion.
2. **A GitHub issue**, at https://github.com/Brainchip-Inc/AkidaTag/issues, for a bug or a
   feature request: it is tracked, and the answer helps the next person. Search the open issues
   first.

For BrainChip Connect, the app has its own documentation at
https://brainchip-inc.github.io/BrainChip-Connect/.

## What to include

- The firmware version. In the app, the **i** button in the header opens **Device Information**;
  the version is also printed on the release file name.
- The app version, from Google Play or from the app's settings.
- The phone model and its Android version.
- What the LEDs show when the problem happens. See
  [What the LEDs mean](user-guide.md#2-what-the-leds-mean).
- What you did, step by step, and what you expected.

## Security

Report a security problem privately, through the repository's **Security** tab on GitHub and
**Report a vulnerability**, rather than in a public issue.
